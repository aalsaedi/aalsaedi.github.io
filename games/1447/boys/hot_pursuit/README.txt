
    HOT PURSUIT
    ---------------
    2D car game made with Phaser.js.


    HOW TO RUN
    =============
    
    Open 'index.html' using a Live Server (VS Code) or any local web server.
    DO NOT just double-click 'index.html' in some browsers—it may not load properly.


    CONTROLS
    =====================

    - Left / Right arrows: Move the car
    - On-screen buttons: Change car, toggle music, switch day/night mode


    GOAL
    ====================

    Survive as long as possible by avoiding traffic and police cars
