README – Platformer Assignment

This folder contains all files related to the Platformer Game Assignment.

Contents
- index.html → Main entry file to run the game in the browser.
- game.js → JavaScript file containing the game logic (Phaser 3).
- sky.png → Background image.
- platform.png → Platform image.
- star.png → Collectible star image.
- dude.png → Player character sprite.
- jump.wav → Jump sound effect.
- Platformer_Assignment_Omar.docx → Documentation report explaining the project.
- Game_Instructions.docx → User manual with gameplay instructions.
- screenshot1.png → Player standing on the platform.
- screenshot2.png → Player jumping.
- screenshot3.png → Player collecting a star.

How to Run
1. Open index.html in a modern browser (Chrome, Edge, Firefox).
2. Use arrow keys to control the player:
   - Left Arrow (←): Move left
   - Right Arrow (→): Move right
   - Up Arrow (↑): Jump
3. Collect stars to increase your score.
