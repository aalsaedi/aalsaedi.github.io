# Coin Hunter

## Game Description
Coin Hunter is a simple and fun 2D platformer game where you play as a blue adventurer. Your goal is to jump across platforms, collect all the gold coins, and reach the highest score possible!


## Gameplay
Navigate through the level using the arrow keys. Jump over gaps and onto platforms to reach the coins. Once you collect all the coins in the level, you win the game!

## Motivation for Playing
- **Challenge**: Test your platforming skills.
- **Satisfaction**: The joy of collecting every single coin.
- **Quick Fun**: A short, accessible game for a quick break.

## Target Audience
- Casual gamers
- Fans of classic platformers
- Beginners learning game development

## Controls
- **Left Arrow**: Move Left
- **Right Arrow**: Move Right
- **Up Arrow** or **Space**: Jump

## How to Run
Simply open `index.html` in your web browser. No installation required!
(Note: For best performance and to avoid local file security restrictions in some browsers, it is recommended to run this via a local server, e.g., VS Code Live Server extension).
